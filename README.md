# RIFT（仮称）

<img src="public/icons/rift-128.png" alt="RIFTのカラスアイコン" width="64" height="64" />

Electron + React + Vite で動く、4chan / 5ch / V2EX（試験対応）/ PTT（公開Web版）の閲覧専用アプリです。
board -> thread -> post/gallery の流れで閲覧し、翻訳と画像保存に対応しています。

## 中国語圏BBSへの対応状況

V2EXはトークン不要の公開モードを標準とし、個人トークンを使う認証モードも選べます（いずれも試験対応）。PTTはログイン不要の公開Web版に対応しました。事前調査は [CHINESE_BBS_RESEARCH.md](CHINESE_BBS_RESEARCH.md)、現在の実装は [SPECIFICATION.md](SPECIFICATION.md) を参照してください。

既存の4chan・5chのお気に入り・履歴・タブは新しい保存形式へ自動で読み替えます。移行だけでは旧データを削除せず、保存済み本文も引き続き読めます。保存領域の異常時は警告を表示し、自動上書きを止めます。全データ消去を選ぶと旧形式の控えも削除されます。新旧バージョンを同時に使った場合のデータ同期には対応していません。

### V2EXの使い方

**まずは公開モード（トークン不要）**

1. 上部の「V2EX」を選び、`python`、`programmer`、`openai`などのノードを開きます。招待コード・アカウントの有効化・トークン設定は不要です。
2. 公式JSON Feedで配信される最新記事と本文を表示します。フィード内の本文が空・省略されている場合があり、全件・全文の取得は保証しません。過去ページ・限定記事は対象外です。
3. 本文下の「公開返信を試験取得」を押して確認すると、その記事の公開APIへ1回問い合わせます。全返信取得は保証せず、続きのページを探索しません。自動取得はありません。
4. お気に入り・履歴・タブ・取得済み本文の端末内保存を利用できます。保存対象は取得済みの範囲だけです。本文の「原文」リンクは外部サイトへの確認を経てブラウザで開けます。
5. 記事URLの内部移動は、この起動中に対象ノードの公開フィードで確認した記事に限ります。URLだけで開けない場合は先にノードを選んでください。お気に入り・履歴からも、現在のフィード外の記事は再取得できません。明示保存済みの本文はオフラインで読めます。

- 公開モードでは保存済みトークンもCookieも送信しません。画像取得は非対応です。DeepL翻訳は既存の確認付き手動操作だけで、自動送信しません。
- フィードと公開返信は最大10分、ノード一覧は最大24時間のメモリキャッシュを使用します。「更新」でも有効なキャッシュを使用します。自動巡回・全記事収集・全文の再公開機能はありません。
- 閲覧拒否・リダイレクト・HTML確認画面等を検出したら公開取得を停止します。VPN・別ドメイン・HTML収集による回避はしません。429はサーバー指定の待機時間を尊重します。
- 公式に案内された配信範囲を使用しますが、公開されていることが無制限の再利用許諾を意味するわけではありません。[公式フィード案内](https://blog.v2ex.com/rss/)・[運営による公開APIとページ送りの説明](https://www.v2ex.com/t/1187622)を参照してください。
- 2026-10-15に実装済みの公開モードでprogrammer/openaiのフィードを匿名の計2要求で確認し、各50件の一覧と各先頭記事の本文変換に成功しました。実サイトの返信は事前調査の公開告知1件のみ確認済みで、新しい画面からの返信操作は模擬応答で検証しています。

**認証モード（任意）**

1. [V2EXの公式案内](https://www.v2ex.com/help/personal-access-token)に従い、自分のアカウントでPersonal Access Tokenを作成します。RIFT用の共通トークンは配布しません。必要最小限の権限・期間を選んでください。`regular`もトークン自体が読み取り専用になるわけではありません。
2. RIFT上部の「V2EX接続設定」で「認証モード」を選び、トークンを入力して「設定する」「接続を確認」を押します。トークンを設定するだけでは公開モードから切り替わりません。チャット・ソースコード・設定の共有ファイルには貼らないでください。
3. 「このPCに保存」はOSの暗号化機能を使用します。オフにすると今回の起動中だけ保持し、以前の保存トークンも削除します。安全な暗号化が使えない環境では永続保存できません。
4. 「V2EX」でノードを検索し、トピックと返信を読みます。`python`、`programmer`、`openai`などを検索できます。「続きの投稿を読み込む」で手動追加します。一覧の検索は取得済みページのみが対象です。
5. お気に入りの板・スレッド、履歴、タブ、取得済み本文の保存を利用できます。`/go/ノード`・`/t/番号`のURLはRIFT内で開きます。ページ・返信位置の指定は無視し、先頭から表示します。

- 原文のプレーンテキスト表示です。Markdownは記号を含む原文のまま表示し、HTML・アバターは読み込みません。対応画像とDeepL翻訳は下記の確認操作後のみ利用できます。返信ツリー・投稿・投票・メッセージ送信には対応しません。
- 通信は約6秒間隔で直列実行します。公開ノード一覧は最大24時間、認証付き取得は30秒のメモリキャッシュを使用します。APIの制限・権限・トークン失効時は案内を表示し、回避のための別ホスト探索はしません。
- 保存するのは取得済みの本文だけです。まだ読み込んでいない返信や、画像・訳文は含みません。保存済み本文はトークンを削除してもオフラインで読めます。
- トークンの削除は「V2EX接続設定」から行います。「閲覧データを消去」とは別です。PC上で削除してもサーバー上のトークンは失効しないため、不要ならV2EX側でも失効させてください。
- WindowsではElectron safeStorageを通じたOS暗号化を利用します。同一OSアカウントで動く悪意あるソフトに対する完全な保護ではありません。閲覧履歴・保存本文は暗号化しません。
- **検証範囲:** 公開ノード一覧と公式API仕様を確認し、認証付き処理は模擬応答・実Electron操作テストで検証しています。実際の個人トークンを使ったAPI応答・ページ送りは未検証のため、試験対応です。

### 認証モードの本番利用前の確認

1. 「V2EX接続設定」で認証モードを選び、個人トークンを設定して「接続を確認」で認証を確認します。公開モードを使うだけなら、この手順は不要です。キーの値はチャットやGitへ貼らないでください。
2. 同じ画面の「認証モードの動作確認」で、確認したいノード名（例: `python`）を入力し「読み取り動作を確認」を押します。通信確認に同意した場合だけ、一覧2ページと、その一覧で返信の最も多い記事1件・返信2ページを取得します。最大6要求、通常約40秒、通信状態によっては数分かかります。
3. 結果の「確認済み」「確認失敗」「未確認」を見ます。空の2ページ目は、記事・返信のある2ページ目の動作確認には数えません。対象ノード・時点を限った結果であり、全機能の正式対応を保証するものではありません。

確認は読み取りのみです。投稿・投票・画像取得・DeepL送信をせず、本文・認証情報・閲覧履歴を検証結果へ保存しません。結果は設定画面を閉じると消えます。トークン変更中の古い確認結果は破棄し、認証拒否時は通常閲覧の古い本文も取り下げます。

**2026-10-15の公開読み取り確認:** このPCから認証なしの7要求で、V2EX公開ノード1,378件・未認証APIの401、PTT人気板128件・Soft_Jobの記事一覧18件・古い一覧20件・記事本文とコメント51件・年齢確認前の遮断を確認しました。PTT記事の画像候補は1件抽出しましたが、画像自体は取得していません。件数は確認時点の値です。V2EX認証後、PTT実サイトの年齢同意後、画像配信、DeepL本番送信は別途確認が必要です。

### PTTの使い方

1. 上部の「PTT」を選び、人気板から記事を開きます。一覧にない板は上部の欄に `Soft_Job` などの板名、または `https://www.ptt.cc/bbs/板名/index.html` を入力してください。記事URLからの内部移動も可能です。
2. 「次のページを読み込む」で古い記事の一覧を追加します。記事の本文とコメントはまとめて表示し、「推」「噓」「→」を区別します。コメントの番号はRIFT内の表示順で、5chのレス番号とは異なります。
3. 年齢確認対象のページでは、確認前に一覧・本文を表示しません。「年齢確認を開く」から、18歳以上で閲覧に同意する場合のみ進めます。キャンセルすると取得結果は表示しません。
4. 同意は今回のアプリ起動中だけ有効です。「PTT年齢確認を解除」で取り消せます。PTTへの通信だけに `over18=1` Cookieを付け、ブラウザのCookieやアカウント情報は使いません。V2EXやDeepLのキーも不要です。
5. お気に入り・履歴・タブ・本文保存を利用できます。人気板以外も記事一覧の「板を登録」から追加できます。保存本文には出典URL・取得日時・作者・コメント種別も残ります。

- 通信は約3秒間隔で直列実行。人気板は5分、記事一覧・本文は30秒のメモリキャッシュを使用します。自動巡回や全分類の一括取得は行いません。
- 年齢確認を解除しても、明示保存済みの本文は残ります。不要な場合は「保存済みスレッド」から削除してください。閲覧データは暗号化されません。
- 投稿・ログイン・分類ツリーの展開は未対応です。旧形式や構造が変わった記事、削除済み・アクセス制限中の記事は読めない場合があります。制限回避や第三者ミラー探索はしません。
- **検証範囲:** 公開板・記事と年齢確認前の遮断は実サイトで確認しました。同意後の閲覧・解除は模擬ページで検証しており、実サイトで同意する操作は行っていません。
- **板の探し方:** 左の「PTTの読み方・板の探し方」を開くと、使い方と `Soft_Job` へのボタンがあります。検索欄に正式な板名を入力して「板名『…』を直接開く」を押すと、人気一覧にない板も指定できます（大文字・小文字を区別）。入力だけでは取得しません。存在しない板や制限中の板はエラーを表示し、別サイトへ転送しません。
- 403・429・503の応答後は最低1分待機し、サーバーの `Retry-After` が長ければその期間を短縮しません。年齢確認を解除しても起動中の待機制限は残ります。連続再試行や再起動による制限回避はしないでください。

### V2EX・PTTの画像と日本語訳

- **画像:** PTTは「画像一覧 (件数)」、V2EX認証モードは「Gallery」で候補を確認できます。「画像を読み込む」の外部接続確認に同意すると、自動で画像一覧へ移動して表示します。本文を開くだけでは画像ホストへ接続しません。
- **PTTでの操作:** 本文・コメントの「画像 N 件を読み込んで表示」からも、確認後に該当画像のページへ移動できます。画像をクリックすると拡大。「この画像を保存」「選択した画像を保存」「画像をすべて保存」でPC内のフォルダへ保存します。「本文を保存」には画像を含みません。
- PTTでは検出件数と「画像が表示されないとき」の説明を表示します。0件は必ずしも取得不具合ではなく、画像のない記事や未対応URLの可能性があります。0件のときは読み込みボタンを無効にします。一覧へ切り替えるだけでは外部画像に接続しません。
- 対応は `i.imgur.com` / `i.postimg.cc` / `i.ibb.co` / `i.urusai.cc` のHTTPS画像直リンクのみ。JPEG・PNG・GIF・WebP、通常1枚20 MiB以下（個別確認後は最大100 MiB）・1600万画素以下です。共有ページ・短縮URL・その他のホスト・動画は対象外です。V2EXのMarkdown内の直リンク、追記・返信、PTTの本文・コメント内の直リンクも対象です。
- URUSAIは `https://i.urusai.cc/shine.png` のような拡張子付き直リンクに対応します（[公式API資料](https://urusai.cc/api)の `url_direct` 形式）。拡張子なしのプレビュー・`/a/` のアルバム・クエリ付きURLは対象外です。APIキーやアップロード操作は不要です。専用テストと隔離したElectronで表示・保存を確認しますが、URUSAI実サーバーの画像取得は未検証です。
- 接続先にIPアドレス等が伝わります。画像通信にはV2EXトークン・PTT年齢確認Cookieを付けません。同意はスレッド切替で解除され、「画像の表示を停止」でも取り消せます。受理済みの通信・保存は完了する場合があります。
- **大きい画像:** 通常上限は20MBです（画面のMBはMiB換算、20×1024×1024バイト）。20MB超は取得を一旦停止し、サイズ・接続先・通信量とメモリへの影響を警告します。「この画像を取得」を選んだときだけ、今回1回に限って最大100MBまで再取得します。表示・拡大・保存ごとに再確認し、許可は永続化しません。サイズ不明なら20MBを超えた時点で中断して確認するため、それまでの通信量は発生します。100MB超は許可できません。形式・1600万画素などの制限は解除しません。
- 大きい画像の警告はキャンセルが初期選択です。保存時のキャンセル・100MB超はその画像を失敗扱いとして次へ進み、自動再試行しません。必要な画像だけ後から手動で再試行できます。この変更は5ch・PTT・V2EX認証モードの外部画像に適用され、4chanの取得経路や本文保存の8MiB上限は変更しません。
- **翻訳:** 一覧の「日本語に翻訳」はタイトル、本文側はその投稿・コメントが対象です。DeepLへの外部送信を確認してから実行し、原文の下に機械翻訳と明示して併記します。自動翻訳・スレッド一括送信は行いません。
- 翻訳には `DEEPL_API_KEY` の設定が必要です。送信してよい内容か確認してください。利用枠を消費する場合があります。1件4,000文字までで、超える本文は切り詰めたり分割送信したりしません。
- 訳文は起動中のメモリのみで、本文保存・履歴には含めません。「原文のみ表示」「訳文を表示」で切り替えられます。PTTの年齢確認前は画像候補・翻訳ボタンも表示しません。
- 画像・翻訳連携は模擬データと隔離した実Electron画面で検証します。実トークンを使ったV2EXや、本番の中国語記事をDeepLへ送信する検証は行っていません。
- 2026-10-15、PTTの公開Soft_Job記事から検出したImgur画像1枚を、通常の画像取得処理で取得・形式検証できることを確認しました。画像はファイル保存していません。PC_Shoppingの公開3記事は画像候補0件でした。少数サンプルの確認であり、すべての画像ホスト・記事に対応する保証ではありません。

## 5ch の使い方
1. ヘッダーで「5ch」を選び、板・スレッドを選択します。板／スレッドURLの入力にも対応しています。
2. 返信参照のプレビュー・移動、ID絞り込み、NG ID・NGワード、AA表示、未読位置への移動を利用できます。
3. 「更新」で再取得します。短時間の連続操作はキャッシュを使用し、本文は可能なら差分取得します。自動巡回はしません。
4. 画像は初期状態では取得しません。外部接続の確認後、画像一覧・拡大表示・個別／選択／一括保存を利用できます。
画像対応は **i.imgur.com / i.postimg.cc / i.ibb.co / i.urusai.cc のHTTPS直接リンク**に限定しています。JPEG・PNG・GIF・WebP、通常1枚20 MiB以下（個別確認後は最大100 MiB）・1600万画素以下（各辺16384以下）が対象です。画像ページ、短縮URL、クエリ付きURL、リダイレクト、その他のホスト、動画には未対応です。画像ホストには接続元IPが伝わります。
画像は同一URLをまとめ、表示対象の投稿から最大2000件を扱います。一覧は12枚ずつ取得し、保存時は安全な生成ファイル名を使います。表示を停止しても、既に受け付けた通信は完了する場合があります。
5chは閲覧専用です。投稿・ログイン・UPLIFT・過去ログの完全対応は含みません。旧5ch.net URLは現在の公式板一覧に照合して5ch.ioの取得先へ解決します。サービス側の制限・変更により読めない板やスレッドもあります。
表示名はRIFTを仮採用しています。既存データを維持するため、内部パッケージ名とユーザーデータ保存先は変更していません。旧4chanの閲覧データは自動移行し、以後はサービス別にお気に入り・閲覧位置・NG設定を保存します。「閲覧データを消去」は全サービスに適用されます（トークンは別途削除）。
## 4chan の主な機能
- 板一覧の取得・検索
- カタログからスレッド一覧表示（先頭50件）
- スレッド表示（THREAD / GALLERY 切り替え）
- 画像の個別保存 / 一括保存
- 投稿テキストの日本語翻訳（DeepL）
- 過去スレの追加読み込み
- 画像のアプリ内拡大表示・左右移動、WebM の再生
- お気に入りの板・スレッド、既読表示、前回の選択とスクロール位置の復元
- 保存キャンセルの表示・二重実行防止・失敗したファイルだけの再試行
- 翻訳結果の一時キャッシュと原文のみ／訳文付きの表示切り替え
## 使い方の補足
- サムネイルをクリックするとビューアが開きます。左右キーで前後へ、Esc で閉じます。動画にフォーカスがある間は左右キーを動画のシーク操作に使います。
- 板の「登録」とスレッドの「お気に入り」で登録できます。お気に入りの板は左ライブラリに並び、スレッドは「お気に入りスレッド」から開けます。
- お気に入り・既読・前回の選択・スクロール位置は PC 内の localStorage に保存します（お気に入りは各200件、履歴は各サイト500件、暗号化なし、クラウド同期なし）。「閲覧データを消去」で削除できます。
- 既読は表示位置までの記録です。削除済みスレッドの復元や、追加で読み込んだ過去スレ自体の再読み込みは保証しません。
- 翻訳キャッシュは起動中のメモリだけに最大200件保持し、終了・画面再読み込みで消えます。原文や訳文を閲覧履歴へ保存しません。
- 拡大ビューアの「この画像を保存」で表示中の1枚を保存できます（4chanのWebMは「この動画を保存」）。保存先の選択、進捗・キャンセル・結果表示に対応。保存中に前後へ移動しても、押した時点の画像が対象です。5ch画像は従来どおり読み込み同意と安全性検証が必要です。
- 保存の再試行では失敗したファイルだけを対象に、保存先を再選択します。キャンセルできるのは保存先選択時です。
## 必要環境
- Node.js 22.12 以上
- npm
- DeepL API Free のキー（翻訳機能を使う場合）
## セットアップ
```bash
npm ci
```
`.env` は自動読み込みしない実装です。実行前に環境変数 `DEEPL_API_KEY` を設定してください。
### Windows (PowerShell)
```powershell
$env:DEEPL_API_KEY="your_deepl_api_key"
npm run dev
```
### macOS / Linux (bash/zsh)
```bash
export DEEPL_API_KEY="your_deepl_api_key"
npm run dev
```
永続化したい場合は、OSのユーザー環境変数に `DEEPL_API_KEY` を登録してください。
登録後はターミナルや起動元のアプリを再起動してください。既に登録済みなら再設定は不要です。
キーをソースコードや共有ファイルに書かないでください。環境変数は暗号化された秘密保管庫ではありません。
翻訳・画像保存・5ch/V2EX/PTT閲覧は Electron アプリ内で利用できます。DeepLキーなしでも閲覧できます。V2EXの公開モードは個人トークンも不要です。Vite の画面を通常のブラウザで開いただけでは利用できません。
## 実行コマンド
- `npm run dev`: 開発起動（Vite + Electron TS watch + Electron app）
- `npm run lint`: 型チェック
- `npm test`: 翻訳・保存・IPC のセキュリティ回帰テスト（実際の API キーや外部通信は不要）
- `npm run verify`: 型チェック・回帰テスト・ビルド・隔離した実Electron操作テストをまとめて実行。GitHubの自動検証もこの手順を使います。
- `npm run check:live -- --allow-network`: ビルド後に実サイトの公開読み取りを最大7件だけ確認。明示オプションなしでは通信しません。認証情報・Cookie・画像・DeepLを使わず、本文を出力せず件数と結果だけを表示します。自動検証では実行しません。失敗時に連続実行せず、通信環境・サイト側の制限を確認してください。
- `npm run check:live -- --allow-network --ptt`: PTTだけを最大5件で確認。V2EXへ接続せず、人気板・Soft_Jobの一覧／古いページ／記事・年齢確認前の遮断を確認します。途中で失敗したら後続の接続を停止し、未確認と表示します。空の古いページも取得内容の検証成功とは扱いません。
- `npm run build`: Renderer/Electron をビルド
- `npm run electron`: ビルド後に Electron 実行
- `npm start`: 既存ビルドを実行
初回および更新後は `npm run electron` でビルドして起動してください。
生成物の `dist/` と `dist-electron/` は Git に含めません。
開発時はポート 5173 を使用します。Electron 側のコードを変更した場合は開発プロセスを再起動してください。
## セキュリティ方針
- DeepL APIキーの直書きは禁止（環境変数のみ）
- 投稿本文はプレーンテキスト表示（HTMLを直接挿入しない）
- 翻訳・画像保存用のローカル HTTP サーバーは起動しない
- 翻訳・保存は送信元を検証した IPC 経由でメインプロセスが実行
- 4chanの画像保存先の通信は `https://i.4cdn.org` の所定の画像・動画パスのみ許可し、リダイレクトを拒否
- API キーはメインプロセスだけで使用し、画面やエラー応答へ渡さない
- V2EXトークンはマスク付き入力から専用IPCへ渡し、設定後に入力欄を消去。メインプロセスのHTTPS認証ヘッダーだけで使用し、取得API・ログ・localStorageには返さない。永続化はOS暗号化のみで平文へのフォールバックなし
- 5ch本文・外部画像は検証付きIPCで取得。許可ホスト・パスに限定し、DNSで内部ネットワークを排除。画像の形式・容量・寸法を検証してから表示／保存
- 外部画像URLは画面の画像要素へ直接設定しない
依存関係を変更した場合は `npm test`、`npm run lint`、`npm run build`、`npm audit` で確認してください。
ビルド後の `node tests/electron-smoke.cjs` は、非表示の Electron ウィンドウで起動と翻訳 IPC を検証します（通信は模擬応答、ユーザーデータは一時領域に分離）。
板の高速切り替え、ビューアのキーボード操作、保存キャンセル、閲覧状態復元・消去、デスクトップ／狭い画面も検証し、画像を `.test-artifacts/` に出力します。
## 自動チェック
`.github/workflows/check.yml` は push / pull request 時にテスト・型チェック・ビルド・Electron 操作テスト・依存関係の脆弱性検査・Gitleaks の秘密情報検査を行います。APIキーを GitHub Secrets に登録する必要はありません。
Gitleaks は現在のファイル全体と、キー失効対応時の `bb93b15` より後のコミットを検査します。それ以前の失効済みキーを含む履歴は対象外で、履歴自体を削除する仕組みではありません。検出値はログでマスクします。
Dependabot は npm と GitHub Actions の更新 PR を週次で作成します。Actions の実行許可や必須チェックの設定はリポジトリ管理者が管理してください。

## 追加機能（2026-10-05）

- 板・スレッドを選ぶとタブに追加します。同じ閲覧先は既存タブへ切り替え、最大20件まで開けます。×で閉じられます。
- タブ一覧はPC内に保存し、再起動後に復元します。スレッドの閲覧位置は既存の保存機能で復元します。非選択タブの自動通信は行いません。
- タブ切替時に画像取得への同意は解除されます。閲覧データ消去ではタブも消去します。本文・画像・認証情報はタブに保存しません。
- 5chの取得失敗時は公式板一覧で移転を再確認（最短60秒間隔）。登録ホストが変わった場合だけ1回再接続し、任意の転送先へは接続しません。403・429・サーバー障害・取得不能・未確認の転送を分けて案内します。削除とDAT落ちの原因は断定しません。
- ImgBBのHTTPS直接画像リンクに対応しました。[公式APIのURL形式](https://api.imgbb.com/)に基づきi.ibb.coのみ許可します。共有ページ・認証付きURL・転送先は対象外です。従来の容量・寸法・形式・DNS検証を維持します。


## ライブラリ（2026-10-14）

左側に「お気に入りスレッド」「閲覧履歴」「お気に入り板」「すべての板」をまとめました。ライブラリを切り替えても、右側の本文はそのまま読めます。以前の上部のお気に入り一覧は左側へ移動しています。

- お気に入りスレッド: タイトル・板名検索、全サイト／4chan／5chの絞り込み、登録順／最近読んだ順。既存タブがあれば再利用します。
- 閲覧履歴: 本文の取得・表示に成功したスレッドを各サイト最大500件記録し、今日／昨日／それ以前に分けます。スクロールだけでは最終閲覧日時を変えません。個別削除と履歴だけの全消去ができます。
- お気に入り板: サイトをまたいで左側に常設。上下ボタンで並べ替えられ、板一覧の取得失敗時も保存済みショートカットは残ります。
- 履歴設定: 「閲覧履歴 → 履歴の設定・消去」で記録を停止できます。停止中は新しい履歴・閲覧位置を記録しませんが、既存履歴・お気に入り・開いているタブ・前回の選択は残ります。完全なプライベートモードではありません。再開後は次に開いたスレッドから記録します。
- タイトル・板名・登録日時・最終閲覧日時・閲覧位置をPC内に保存します。お気に入り・履歴自体は本文を保存しません。本文を残したい場合は、下記の「本文を保存」を使ってください。一覧を開くだけでスレッド本文・外部画像の全件取得は行いません。
- 旧データは自動移行します。タイトル不明は板名・番号で表示し、取得できたときに補完します。旧履歴の日時は以前の閲覧位置更新時刻から引き継ぎます。既に上限で消えた履歴は復元できません。
- お気に入りは板・スレッドそれぞれ各サイト200件。履歴削除はお気に入りやタブを閉じません。「閲覧データを消去」は両サイトの閲覧情報・タブ・保存済み本文を消去します。

## スレッド本文の保存・外部リンク

- スレッド画面の「本文を保存」で、取得済みのそのスレッドの本文をPC内に保存します。同じスレッドを再保存すると置き換えます。
- 左の「保存済みスレッド」から検索・閲覧・個別削除・全削除できます。保存した本文を開く操作では通信せず、再起動後やスレッド取得不能時も保存時点の内容を読めます。通常閲覧へ戻ると再取得します。
- 保存対象は投稿番号・名前・日時・ID・本文です。画像・動画・訳文は含みません。画像は従来の保存ボタンで別途保存してください。NGで非表示の投稿も取得済みなら保存対象です。「Load older thread」で追加した別スレッドは含めません。
- 上限は1スレッド8MiB・10,000投稿、全サイト合計100件・50MiBです。上限時は既存データを消さず案内します。
- 本文はアプリのIndexedDBに保存します（暗号化・同期・ファイル書き出しなし）。ブラウザの保存領域削除やアプリ配置変更等で失われる場合があります。「閲覧データを消去」は保存済み本文も削除します。
- お気に入り板は名前・サイト・操作ボタンを1行に集約しました。長い板名はマウスを重ねると確認できます。
- 本文のHTTP/HTTPS URLは色付き・下線付きです。認識できる5ch板・スレッドURLはRIFT内で開きます。それ以外のリンクのクリック時は「外部サイトへ遷移します」と接続先を表示し、「ブラウザで開く」を選んだときだけ既定ブラウザを起動します。初期選択はキャンセルです。画像の「Open full」にも同じ確認を適用します。

## 前スレリンク・公式過去ログ

- 本文・返信プレビュー・保存済み本文の5chスレッドURLをクリックすると、外部ブラウザを開かずRIFTのタブで表示します。同じスレッドのタブがあれば再利用します。旧 `5ch.net` と現行 `5ch.io` に対応し、クリックしたホストではなく公式板一覧の取得先を使用します。
- 通常DATが404/410の場合は公式板一覧で移転を確認したうえで、現行の公式サーバーの公開過去ログDAT（`/板/oyster/先頭4桁/スレッド番号.dat`）を1回試します。取得できた場合は「公式過去ログ」と表示します。
- 403・429・サーバー障害・不正な応答でのアーカイブ切替、認証制限の回避、第三者アーカイブの探索は行いません。現行公式サーバーに収録されていない古い過去ログなど、読めないスレッドもあります。失敗してもブラウザへ自動転送しません。
- 過去ログも本文保存・画像一覧の対象です。画像の読み込みは従来どおり別途同意が必要です。保存済み本文を読むだけでは通信しませんが、そこにある5chリンクをクリックすると取得のため通信します。
- DATの公開取得形式の参考: [5ちゃんねるの公式告知](https://fate.5ch.io/test/read.cgi/momoclo/9240230711/l50)。
